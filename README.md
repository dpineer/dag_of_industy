# 工业生产链模拟器 (Industrial Production Chain Simulator)

一个基于Flutter的工业生产链模拟器，支持复杂的生产流程建模、资源流转分析和自动化控制。

## 功能特性

### 1. 基础建模功能
- **节点类型**：支持多种工艺分类（原材料、加工、组装、精炼、发电、控制等）
- **端口配置**：灵活的输入/输出端口配置，支持自定义物料名称、速率和单位
- **堆叠机制**：同类节点可自动堆叠，提升生产效率
- **建设模板**：支持建设资源模板配置，可定义建设所需资源

### 2. 资源流转系统
- **库存管理**：实时跟踪各节点的输入输出库存
- **连接系统**：支持节点间的物料连接，自动验证物料名称匹配
- **容量限制**：每个节点具有最大容量限制，防止无限存储
- **污染处理**：支持污染物标识和丢弃机制

### 3. 模拟引擎
- **时序调度**：基于时间步长的精确模拟
- **状态判定**：自动检测节点运行状态（运行、缺料、堵塞）
- **堆叠倍增**：堆叠节点的输入消耗和输出产生按堆叠数量倍增
- **网络流转**：基于连接拓扑的物料自动流转

### 4. 逻辑自动化
- **控制卡片**：支持逻辑控制卡片，可执行建设、启动、停止、拆除等指令
- **条件控制**：支持多种条件判断（数值比较、运行状态、建设状态等）
- **目标指定**：可指定控制目标节点和监测对象
- **触发机制**：条件满足时自动执行控制指令

### 5. 用户界面
- **拖拽操作**：支持节点拖拽和连线操作
- **实时编辑**：支持节点属性的实时编辑
- **状态显示**：直观显示节点运行状态和进度
- **建设资源标识**：建设资源以蓝色标识显示

## 使用方法

### 基础操作
1. **添加节点**：点击"添加节点"按钮创建新的生产节点
2. **配置节点**：双击节点打开配置对话框，设置名称、分类、端口等
3. **连接节点**：拖拽输出端口到输入端口建立物料连接
4. **启动模拟**：点击"开始模拟"按钮启动生产链模拟

### 高级功能
1. **创建控制卡片**：添加控制类型的节点，配置自动化指令
2. **设置条件控制**：在控制卡片中配置条件判断逻辑
3. **配置建设模板**：在节点中设置建设所需的资源模板
4. **调整堆叠数量**：同类节点靠近时自动堆叠

## 技术架构

### 核心组件
- **CanvasState**：管理画布的整体状态
- **CanvasNotifier**：处理所有状态变更逻辑
- **ProductionNode**：表示生产节点的数据模型
- **Connection**：表示节点间的连接关系

### 模拟引擎
- **_simTick**：核心时序调度引擎，处理资源流转和状态更新
- **executeLogicTick**：逻辑自动化控制执行引擎
- **_evaluateCondition**：条件判断评估方法

### UI组件
- **NodeWidget**：节点的可视化组件
- **NodeEditDialog**：节点编辑对话框
- **GraphAnalyzer**：图论分析器

## 设计理念

本模拟器采用DAG（有向无环图）结构建模工业生产链，通过节点和连接构建完整的生产流程。系统支持多层次的抽象，从单个节点的微观操作到整个生产链的宏观分析。

## 应用场景

- 工业生产流程设计与优化
- 资源配置与调度分析
- 自动化控制系统建模
- 生产效率评估与改进
- 环境影响评估（污染物处理）
